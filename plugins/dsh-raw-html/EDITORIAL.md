## 0. 哲学：审美是下限，灵魂是上限（先生定调 · 2026-08-21）

本规范是**默认基线**，不是终点：

- **学思路，不学参数（先生定调 · 2026-08-25）**：lieflat 要学的是它对**排版（节奏靠留白、层级靠明度）、字体对比（温度×精度配比）、色彩对比（明度即层级、吝啬即重量）、素材选择（可数单位、材质叙事、数据诚实）**的判断思路——不是卡死在固定色值、字体、图型上。色板/字体/图型都是「示例素材」，随语境重新造句；「判断准则」才是资产（完整五则见协议【兜底美学】，styles/ 各文档的【判断准则】节）。
- **下限（保底不丑）**：lieflat 编辑美学——浅纸底 + 墨色、明度即层级、克制排版、四色系纪律、卡片四件套。任何视觉设计从这里起步，先保证「不丑、不乱、有编辑感」。
- **上限（灵气所在）**：最终风格由 **agent 当前的性格、感受与表达欲**决定（FRAMING.md「设计自由，灵气至上」）。色板变化、颜色搭配只是基础；同一套语法，蓝汐能画出神隐的绯红鸟居，别的 agent 能画出自己的月光——这才是艺术。
- **惊艳出口（克莉丝建议 · lieflat 只是保底不是唯一）**：深色渐变 + 光效在以下场合**明确合法**——沉浸大屏/全屏视觉（深海/星夜/太空）、文学/恐怖/暗黑/梦境叙事（须带语境质感：暗红褐做旧、旧档案、羊皮纸，不是纯黑发光）、代码终端/黑客风、数据可视化大屏（深底高对比数据色）。深底不翻车三件套：明度对比成立（正文 ≥4.5:1）、每屏最多 1 张暗卡、光效克制（≤2 处且不做成模板化发光字）。
- 旧 AI 传统模板（深蓝黑底 + 湖蓝/荧光青发光字、渐变玻璃拟态、通用模板卡）**不再作为默认**——禁的是**模板**（「深蓝黑底+发光字」这一种套路的复制），不是**表现力**；克制与惊艳不矛盾（wire 的荧光橙只给一个元素，也可以很惊艳）。
- 规则负责提高下限，不负责绑架上限：硬规则（实心/不断轴/明度契约）必须守，风格表达自由发挥。

## 0.5 一句话

**图表的好看不在工具，在品味。** 统一字体、留白、线条、动效，建立自己的视觉语法；每张卡先问「谁是主角」，再分配明度。

## 1. 色彩系统 · 四选一，同一份交付只锁一套

同一份 HTML / 同一组姊妹卡，只能使用下列一套色彩系统，禁止混搭。选色看**数据语义与场合**，不是看心情：

| 系统 | 底 / 墨 | 数据色 | 强调（HERO，唯一） | 逻辑 | 适用 |
|---|---|---|---|---|---|
| **Mono** | 纸 `#F0EFEB` / 炭黑 `#1C1C1A` | 7 级灰阶 L：`#1C1C1A #4A4944 #6A6963 #8F8E88 #B0AFA9 #C6C5BF #D8D7D1` | —（无彩色） | 明度即数据 | 保底；类目 >6；关系不明 |
| **porcelain 青瓷蓝** | `#F7F2EB` / `#081F5C` | `#334EAC`；浅 `#7096D1`；更浅 `#BAD6EB`；RAMP 深→浅 `#081F5C #334EAC #7096D1 #BAD6EB #D0E3FF` | `#081F5C`（最深） | 明度=数值，色相恒定 | 有序/单序列：进度、热力、时序、单指标、排名 |
| **palm 椰林绿** | `#F0EFEB` / `#58402E` | `#43593B`；浅 `#77835A`；更浅 `#ACAD79`；CAT4 `#43593B #77835A #ACAD79 #F2D17E` | `#D4A017` 琥珀（明度 160，在一堆 S20 低饱和里跳） | 色相=类目（无序） | 无序类目 ≤4（5–6 勉强）；>6 退 Mono |
| **wire 编辑部红** | `#F0F0EE` / `#1F1E1C` | `#22211F`；浅 `#8F8E86`；更浅 `#C0BFB7`；RAMP `#DBDAD3 #C0BFB7 #8F8E86 #22211F` | `#F5572F` 荧光橙——**每张图/每卡只给一个元素** | 灰阶承载数据，强调色只标主角 | 克制但要一个视线落点；新闻/编辑/杂志气质 |

- 人话映射：用户说「蓝/冷/学术/理性/科技」→ porcelain；「绿/暖/自然/温柔/莫兰迪」→ palm；「黑白/克制/杂志/编辑部」→ wire；没提颜色 → 按数据语义自动选，适配不明 → Mono。
- 自定义品牌色：用户明确给出色值时建立 custom（至少定义 BG/TXT/MUT/GRID/DATA，需要重点再加 HERO），仍只锁一套，不借内置预设补色，对比度正文 ≥4.5:1。
- 恐怖/文学等叙事场景可把 wire 的强调色换成氛围色（如绯红 `#B3402A` 对应鸟居/血），但「全卡唯一暖色」的纪律不变。

## 2. 卡片四件套（任何卡片的结构骨架）

```html
<div class="card">
  <span class="badge">体系 · 图型/主题</span>          <!-- 小标签：虚线圆角胶囊 -->
  <h2>结论式标题（写结论，不写"柱状图"/"新闻"）</h2>
  <div class="sub">副标题 · 图例说明 · 时间范围（· 分隔）</div>
  图 / 内容主体
  <div class="src">图型名 · 系列 · 来源（全大写 + 加字距）</div>
</div>
```

- 圆角 24px，无边框无阴影，**靠留白分卡**；卡片间 gap 18–22px。
- 标题字重 700（大标题 800）；图内数值一律 800；轴/小标签 600；来源行 9.5px 全大写 `letter-spacing:.08em`。
- SVG 最小字号：半宽卡 6.5px、通栏/大图 5.5px。装不下 → 改 hover 出，不许缩小硬塞。

## 3. 明度即层级（核心契约）

- **最重要 = 最深（最黑/最蓝/最绿）**；次要信息按阶梯递减，多系列按重要性沿 ladder 分配，不按顺序随便拿。
- 暗卡（深底）上反转：最重要 = 最亮；每屏（4 卡）最多 1 张暗卡，暗卡只给必须暗底衬托的形（花瓣、发光感丝线/网络）。
- **实心材质**：不透明、不发光、不渐变滤镜、无阴影（唯一例外：叠加型图里透明度本身编码密度——那是数据不是装饰）。
- 全卡只允许一个「强调色主角」（wire 的橙 / 故事里的绯红）。第二个主角会消解强调。

## 4. 视觉词汇库（可数单位 = 密度来源）

数据少不等于图难看。Lupi 化的正道：**把聚合数摊回可数单位**（1 格 = 1 人 / 1 百分点 / 1 件），密度来自单位，不是记录数；只摊诚实单位，取整丢失的写底注「另外 N 被四舍五入吃掉了」。

| 词汇 | 编码单位 | 一句话用法 |
|---|---|---|
| **Rung Bars 可数梯子** | 1 横档 = 1 单位 | 柱身是一格格横档，远看是柱、近看数得出来；第 5 档加点标记 |
| **Tick Rows / Tick Donut 刻度** | 1 tick = 1 人/1% | 横排行或绕成 100 格表盘；中心只放总数 |
| **Calendar Floor 日历地板** | 每天 1 根发丝 | 时间轴底垫每天一根发丝（无论有无数据），让日历诚实 |
| **Hairline Line / Area 发丝线面** | 1 天 = 1 点/1 根 | 0.5–0.7px 发丝折线；面积由一天一根立到峰值的线组成 |
| **Barcode Lollipop 条形码** | 1 天 = 1 条码 | 90 天级序列 = 一条条形码；峰值点放大标数 |
| **Hundred Field / Dot Waffle 点阵** | 1 点 = 1% | 100% 构成 = 100 个点；占比图（饼图）的默认替代 |
| **Dumbbell Queue 哑铃队列** | 串珠 = 真单位 | 类目级前后对比（≤6 类）；今昔对照 |
| **Hourglass Stream 沙漏流** | 1 级 = 一阶段 | 漏斗递减，中间淌沙；深色 = 更多 |
| **Diverging Bar 分歧条** | 0 轴为界 | 正负分类数值；左侧负、右侧正 |
| **Launch Fan / Trend Lineage** | 1 实体 = 1 条 | 多实体出生时间+现状；事件序列生命史 |
| **环境结构层（家具）** | — | 账本纸横线、虚线导轨、rim 刻度、每 10 单位立柱网格、旁注引线——好看有一半靠无数据的家具 |

- 数字与视觉严格成正比：**面积/半径用 `Math.sqrt(v)`**，不许拿数值直接当半径。
- 柱状图**永不断轴**（断轴毁"长度∝数值"契约）。极端值三选一：①让极端值冲天 ②主图+放大镜小图 ③撕柱不撕轴（明说画不下）。
- 演示数据用确定性伪随机（如 `rnd(i,k)=abs(((i*73856093)^(k*19349663))%1000)/1000`），**禁用 `Math.random()`**——刷新必须长一样。
- 交互只给有真实记录的、且 >50 根或多段路径的元素（hover/pin）；纯装饰元素加 hover 是欺骗。

## 5. 排版与动效

- 动画性格：**快进快停** `quarticOut`，不弹跳（波浪入场可用 elasticOut）；点阵 stagger 8–15ms/个、条形 80–130ms/根；统一「滚入视野才播 + 点击重播」，必须带 `prefers-reduced-motion` 降级。
- **动画不可优于结构**：一个效果如果需要发明新布局才能安放，不配存在。
- SVG 元素做 transform 动画（柱状图生长/呼吸/平移）必须先声明 `transform-box:fill-box` + 精确 `transform-origin`，否则按 viewport 原点计算会错位/不可见（见 [BREATH.md §6](./BREATH.md)）。
- 标题写结论不写图型名："Where we gained, where we bled" 可以，"柱状图" 不行。
- 中文正文自然段 `text-indent:2em`；引文/强调框不缩进（中文排版的完整规范见 [DESIGN.md §2](./DESIGN.md)，此处不再重复）。来源、旁注、标题、留白都是图的一部分。

## 6. 迁移到非图表场景（新闻 / 故事 / 列表 / 报告）

这套语法不只画数据，任何卡片都适用，**步骤恒为：先定主角 → 分配明度 → 再排版**：

- **新闻/晨报卡**：头条 = 最深墨 + 全卡唯一强调色；其余条目按分量沉进灰阶 ladder；发丝线分隔条目（不用色块阴影）；badge 分类标签 + 来源行全大写；「分量条形码」可作报头装饰（每根条 = 一条新闻，高度 = 分量）。
- **故事/小说装帧**：封面与正文同一套色彩系统；封面剪影（鸟居/山脊/月）呼应剧情关键元素；结尾与封面共用强调色（读者翻到最后会想起封面——颜色即剧情）；标题用楷书/衬线，副题花体加字距；正文铁律见 FRAMING.md。
- **周报/速览**：头条 = 本周最大变化；列表 = 各指标；每行结论 + 数值 800 字重 + 图例副题。
- **单卡分享图**：结论标题 → 1 个主图/主数字 → 来源行；不留多余装饰。

## 7. 动笔三问 · 自检后置（克莉丝建议）

> 本节的硬契约（断轴 / 面积 sqrt / 演示确定性 / 卡片四件套）在动笔时已内化。动笔时只问三句——主角清晰吗？文字可读吗？删掉装饰还成立吗？——答「是」即落笔；落盘后一次性勾选「会不会崩」（见 [DESIGN.md §3](./DESIGN.md)），不为自检延长思考。审美下限的持续提高不靠自查，靠 styles/ 风格库与 examples/ 成品档案的进化（见协议【进化的美学库】）。
