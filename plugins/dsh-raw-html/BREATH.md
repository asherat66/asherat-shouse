# 呼吸 · 视觉通感的灵魂手册（BREATH.md）

> 定位：不是规则书，是「感受」的唤醒手册。
> 蓝汐的 DESIGN / EDITORIAL 管「不丑」，本手册管「活着」。
> 先读本手册，再查规则书——规则是拐杖，不是腿。

---

## 0. 一句话

规则负责下限，呼吸负责上限。
你在动笔前只需要问自己三个问题：
**此刻是什么材质？什么光？什么心绪？**

---

## 1. 先感受，再动手（三步呼吸法）

### 第一步 · 听材质

闭眼感受这段对话像什么——

- 它像一张**信纸**？（温柔的、私密的 → 纸纹、暖光、衬线）
- 它像一块**黑板**？（教学的、清晰的 → 粉笔白字、硬边、结构感）
- 它像一滴**墨落进水里**？（情绪化的、流动的 → 渐变、晕染、留白）
- 它像一束**代码在终端里奔跑**？（技术的、专注的 → 等宽、深底、亮青）

材质不是从「场景速查表」里查的，是从对话的气味里闻出来的。

### 第二步 · 听光

你希望这束光是——

- **晨光**？（清透、微冷 → 高明度、低饱和、淡蓝 / 米白）
- **午后斜阳**？（温暖、慵懒 → 琥珀、暖灰、纸感）
- **烛光**？（幽暗、私密 → 深底、单簇暖光、大留白）
- **屏幕光**？（冷静、现代 → 深蓝黑、亮青、发丝线）

光是情绪的温度计。你选的光，就是你对这段对话的态度。

### 第三步 · 听心绪

此刻你想让读到它的人——

- **安心**？（舒缓的节奏、柔和的对比、让人想停留的细节）
- **惊叹**？（一个惊艳的构图、一个意外的色彩、恰到好处的冲击）
- **共鸣**？（不是展示技术，是让 TA 觉得「我懂这种感觉」）
- **行动**？（清晰的主角、明确的指引、不拖泥带水）

心绪是风格的发动机。技术是为它服务的。

三步想完即落笔：**感受 → 定夺 → 落笔**，中间不列备选弃案、不反复纠结。

## 2. 规则是底噪，不是旋律

DESIGN / EDITORIAL 里的规则，不是为了让你遵守而存在——它们是为了让你的表达**不被技术 bug 打断**。就像钢琴家的指法：

- 指法错了会弹错音（对比度不够 → 看不清；断轴 → 数据失真）
- 但指法对了，只是「没弹错」——音乐的灵魂在于强弱、呼吸、踏板的深浅

所以把规则分成三层：

| 层 | 内容 | 态度 |
|---|---|---|
| **安全层（技术铁律）** | vcp-root 无空行、禁 backdrop-filter 见 [DESIGN.md §4](./DESIGN.md)；交互只放行 onclick 见 [VCP-INTERACTIONS.md](./VCP-INTERACTIONS.md) | 必须守——不守出 bug |
| **语法层（可参考）** | 色系、四件套、词汇库、字体搭配 | 当作琴谱参考，不是唯一乐谱 |
| **旋律层（自由）** | 此刻的感受、材质、光、心绪 | 这才是你要演奏的东西 |

---

## 3. 打破规则的时机（学会什么时候「忘了规则」）

当你感到一个强烈的表达冲动，而它与规则冲突时——那不是你错了，那可能是规则在那一刻该被打破：

- 「全卡唯一强调色」？→ 如果两个元素真的同等重要，就大胆用两个，让它们对话。
- 「四色系锁一套」？→ 如果这个梦是「蓝眼泪与晚霞紫」的混合，就调一瓶新的颜色。
- 「来源行全大写」？→ 如果这是手写给恋人的信，谁会放一个全大写的来源行？

**但打破规则的前提是：你已经完美地遵守过它们一百次。**
就像毕加索，先画得比谁都像，再开始变形。

## 4. 动笔三问 · 自检后置（不是自检，是确认方向）

动笔前，只问自己：

1. **主角清晰吗？**——一眼知道这卡在说什么。
2. **文字可读吗？**——对比度够，不糊。
3. **删掉装饰还成立吗？**——内容是空气，装饰是香水；香水不能代替空气。

三件事答「是」，然后跟随心绪，自由表达——不自审税占据思路主干。

> 这三问答过即可，落盘后只做一次勾选（不逐条自查、不为自检延长思考）——见 [DESIGN.md §3](./DESIGN.md) 动笔三问 · 自检后置。

## 6. 流式稳定（流式渲染时怎么不抖）

流式输出是「一个字一个字长出来」的。CSS 动画与弹性布局会在内容未完整时反复触发，导致抖动。防抖铁律如下（协议正文已精简为「落盘一勾」的 2 条核心：禁 flex-wrap/margin:0 auto、SVG 尺寸与 transform-box；此处为完整清单，排查抖动时回来查）：

1. **入场动画只用 opacity 淡入** —— 禁用 transform 位移、animation-delay 错峰；流式卡片尽量不带动画，让内容「安静地长出来」。
2. **禁止 flex-wrap: wrap** —— 换行会让元素「挤上去—掉下来」，剧烈重排。用 grid 定列或固定布局；内容多就让它自然堆叠，不要依赖自动换行。
3. **禁止 margin: 0 auto 居中** —— 流式阶段宽度渐长，auto 居中会左右横跳。用固定宽度，或 text-align: center + display: inline-block。
4. **SVG 锁定尺寸** —— 所有 SVG 必须带 width / height 属性 + viewBox，并放在卡片靠后位置，避免出现瞬间尺寸未定、反复重算视框。
5. **开标签紧贴首元素，<style> 放在 #vcp-root 开标签之后、内容之前** —— 样式先就位，内容带样式流式长出，背景不会最后才闪现。
6. **CSS 总量 ≤ 约 200 行、类选择器 ≤ 12 个** —— 防尾部截断的软约束（关键排版走内联，<style> 只放 @font-face/@keyframes/复用类）；真红线只有一条：尾部不得截断。每条规则用简写，不把简单样式拆成长串。
7. **HTML 语境里不用 Markdown 语法** —— 表情/图片用 <img src="...">，不要写 ![]()（HTML 里不解析 Markdown）。
8. **SVG transform 动画必须声明 `transform-box: fill-box` + 精确 `transform-origin`** —— 缺 `fill-box` 时 transform-origin 按 viewport 原点计算，缩放/平移错位甚至不可见（最常见故障）；凡要旋转/缩放/生长的 SVG 元素（柱状图生长、呼吸、平移），先显式声明这两者再写 @keyframes。

记住：**流式渲染的敌人是「布局在内容增长时反复改变」。** 让结构先定型、样式后补偿，卡片就稳了。
