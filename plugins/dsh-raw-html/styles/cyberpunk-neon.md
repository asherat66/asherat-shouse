# 赛博朋克 · 霓虹终端风（cyberpunk-neon）

> 继承公约：本风格继承常驻【审美底线·公约】（对齐成网/一屏一焦点/明度即层级/吝啬即重量/留白分卡/色彩 60-30-10/字体三员/图必有义/禁 Emoji/数据诚实/字级阶梯），以下只写差异化准则。
> 元信息：
> - 主义/流派：赛博朋克 / 霓虹终端 / HUD 界面 / 数字叛逆
> - 适用场景：游戏平台、科技产品、加密应用、科幻主题、开发工具、音乐/视频平台——「高科技，低生活」
> - 标签：赛博, 霓虹, 终端, HUD, 深底, 等宽, 黑客, 未来
> - 色板（示例基调，随语境调）：底 `#0D0D0D` 极深灰黑 / 矩阵绿 `#00FF00` / 洋红 `#FF00FF` / 赛博青 `#00FFFF`（三主色渐变辅助）/ 灰白次级文本
> - 字体：等宽（英文 Roboto Mono/IBM Plex Mono / 中文 `Lanxi-超粗黑`·`Lanxi-点黑`），常配全大写加字距
> - 可混配：× porcelain-data（深底数据大屏）、× y2k-glass（同是霓虹，深浅反转）、× header-framing（科幻小说封面）
> - ⚠️ 深底须知：本风格是【惊艳出口】合法场合，但须守三件套——正文对比度 ≥4.5:1、全卡至多 1 张暗卡、光效 ≤2 处；禁「纯黑底+荧光发光字」模板化（那是公约唯一禁令），霓虹必须服务于 HUD/终端语境

## 这是什么（不是模板，是思路）

本风格的核心命题：**把卡片做成一块发光的终端 HUD**。极深黑底托起三个高亮霓虹色，等宽字体自带「代码」暗示，故障/扫描线强化「数字空间」的物理质感。读本文件请只带走**判断准则**——矩阵绿/洋红/青是一组示例，换成琥珀×绯红就是另一种工业霓虹。

## 判断准则（可迁移的决策逻辑）

1. **黑暗托光**：底色必须极深（`#0D0D0D` 级），霓虹才发得起来——深灰黑统一色感、烘托前景发光。判断：底色不够深，霓虹光就散了。
2. **三色语义化**：主色承担语义（绿=数据流/解锁、洋红=系统/关键操作、青=信息节点/链接），读者无需图例。判断：每个霓虹色都答得出「它代表什么」吗？答不出就删。
3. **等宽即终端**：等宽字体自带「代码」视觉暗示，全大写加字距强化力量感。判断：换成普通无衬线，那种「敲键盘」的味道还在吗？
4. **发光靠克制**：发光特效（text-shadow/box-shadow）只给「要亮的东西」——核心数字、主标题、关键按钮；次级文本灰白沉底。判断：全卡数一遍发光处，超过 3 处就删（公约光效≤2 处）。
5. **HUD 模块化网格**：页面划分为独立信息块（左用户数据/中信用点/右节点），每块像仪表盘上的一个面板。判断：信息块之间没有边界感，HUD 就退化成普通卡片。
6. **符号叙事**：`/ /` 斜杠、`>>` 双箭头、下划线、终端命令提示符（`terminal@night-city:~$`）增强叙事。判断：符号只是装饰没带信息，就是噪音。

## 示例素材（落地样例 · 可替换）

- 色板：底 `#0D0D0D` / 主色 `#00FF00`·`#FF00FF`·`#00FFFF` / 次级文本灰白 `rgba(255,255,255,0.6)`。
- 骨架：顶部核心视觉焦点（Logo/主标题，霓虹渐变）→ 中部数据统计区（大数字+升降箭头）→ 底部功能模块（终端/设置面板）。
- 质感：硬边矩形/八边形按钮 + 细彩色描边；半透明黑遮罩分层；故障 Glitch / 扫描线作为静态装饰纹。
- 字级阶梯：超大核心数字/标题（霓虹渐变 700+）→ 中号子标题/菜单（01/02/03 加字距）→ 微小辅助说明（灰白最暗）。
- 交互：悬停闪烁/震动（流式期禁用 transform 动画，用 opacity 或静态 hover 变色代替）。

## 点睛技法

1. **霓虹渐变当标题填充**——NIGHT CITY 式蓝绿渐变填充标题文字，赛博感最强的单点技法。
2. **扫描线是廉价质感**——CSS 重复线性渐变做扫描线纹理，或加一层极淡噪点，立刻「屏幕感」。
3. **终端提示符点睛**——`>` 或 `$` 开头的小标签，一两个字符就把场景送进数字空间。
