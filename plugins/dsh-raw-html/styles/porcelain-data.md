# 青瓷蓝 · 数据风（porcelain-data）

> 继承公约：本风格继承常驻【审美底线·公约】（对齐成网/一屏一焦点/明度即层级/吝啬即重量/留白分卡/色彩 60-30-10/字体三员/图必有义/禁 Emoji/数据诚实/字级阶梯），以下只写差异化准则。

> 元信息：
> - 主义/流派：功能主义 / 学术编辑（有序单序列，明度即数值）
> - 适用场景：数据汇总、周报、技术分析、指标对比、进度、时序、排名、学术/理性讨论
> - 标签：数据, 学术, 理性, 蓝, 冷, 时序, 单序列
> - 色板（示例基调，随语境调）：底 `#F7F2EB` / 墨 `#081F5C` / 数据 `#334EAC → #7096D1 → #BAD6EB → #D0E3FF`（深→浅）/ 强调用最深 `#081F5C`
> - 字体：正文系统无衬线；大标题可用楷书（Lanxi-WenKai）衬出书卷气，或 `Lanxi-静黑超细`/`Lanxi-点黑` 出极简科技感（外置大库）

## 这是什么（不是模板，是思路）

本风格的核心命题：**数据是主角，颜色只负责编码数值**。当内容是一组有序、可排序、有时间轴的数值时，就用「同一色相、明度即数值」的语法把它讲清楚。读本文件请只带走**判断准则**——文中的色值只是某个语境的示例，换一种数据语义必须重新选色。

## 判断准则（可迁移的决策逻辑）

1. **色相恒定，明度编码数值**：有序单序列用同一色相的深浅阶梯表达大小，读者无需图例也能读出排序。判断：数据有天然顺序（时间/数值/排名）→ 单色相阶梯；数据是无序类目（类别/分组）→ 换 palm 的色相区分，别混。
2. **最重要=最深，不给第二色相**：头号数值用全卡最深的墨蓝，不用跳色——「最重」由明度表达，比加粗/变色更干净。判断：强调处问「它是不是全卡最深」，是就对了。
3. **纸感托冷色**：背景用极浅米白而非纯白——微微偏暖的纸底和冷蓝数据色形成「纸与墨」的张力，避免数据卡常见的廉价纯白感。判断：底色答得出「为什么不是白」吗？
4. **可数单位优先**：把聚合数摊回 1 格=1 单位（Rung Bars / Tick Rows / Dot Waffle / Hairline Line）——密度来自单位，不来自装饰。判断：这张图「数」得出来吗？

## 示例素材（落地样例 · 可替换）

- 色板：底 `#F7F2EB` / 墨 `#081F5C` / 数据阶梯 `#334EAC→#7096D1→#BAD6EB→#D0E3FF` / 强调 `#081F5C`。
- 骨架：badge 虚线胶囊（青蓝描边）→ h2 结论标题 → sub（·分隔图例/时间）→ 图/主体 → src 来源行。
- 字级阶梯（先生定调 · 六大类）：主标题 20px/800 墨蓝（或楷书衬书卷气）→ 副题 13px/600 青蓝 → 正文 13.5px 系统无衬线 → 后记 11.5px 淡青蓝 → 装饰 badge 10.5px → 来源行 9.5px 全大写加字距（全卡最弱）。
- 图型：Rung Bars（1 横档=1 单位）、Tick Rows（1 tick=1%）、Dot Waffle（1 点=1%）、Hairline Line（1 天=1 点，0.5-0.7px）；面积用 `Math.sqrt(v)`；柱状图永不断轴；演示数据用确定性伪随机。

## 点睛技法

1. **强调用最深的墨蓝，不用跳色**——最重要的数据用全卡最深的 `#081F5C`，与色板同族不破坏锁定（判断准则 2 的实证）。
2. **同色相浅阶当次序列**——`#7096D1→#BAD6EB` 天然带「递减」语义，读者无需图例也能读出排序。
3. **纸底而非白底**——`#F7F2EB` 微微偏暖，和冷蓝形成「纸与墨」的张力。
