# 编辑部红 · 新闻晚报风（wire-news）

> 继承公约：本风格继承常驻【审美底线·公约】（对齐成网/一屏一焦点/明度即层级/吝啬即重量/留白分卡/色彩 60-30-10/字体三员/图必有义/禁 Emoji/数据诚实/字级阶梯），以下只写差异化准则。

> 元信息：
> - 主义/流派：编辑部 / 报纸印刷 / 杂志编辑
> - 适用场景：新闻、晚报、热点播报、榜单、杂志、公告、信息流简报
> - 标签：新闻, 报纸, 杂志, 榜单, 克制, 编辑, 热榜
> - 色板（示例基调，随语境调）：底 `#F0F0EE` / 墨 `#1F1E1C` / 灰阶 `#DBDAD3 → #22211F`（浅→深）/ 强调荧光橙 `#F5572F`（每卡只给一个元素）
> - 字体：刊头可用英文花体（Lanxi-GreatVibes）或宋体拉仪式感；正文系统无衬线
> - 大字主标题书法体（先生 2026-08-28 入库）：大气首选 `Lanxi-鱼尾行书`（行书带鱼尾收笔，日报/晚报/头条刊头最稳），狂放可选 `Lanxi-狂派手书`（泼墨狂草，战报/热榜/大事件）；篆书 `Lanxi-游龙篆书` 留给文化栏目题花（商用需授权）

## 这是什么（不是模板，是思路）

本风格的核心命题：**信息是版面，克制是编辑**。新闻、榜单、简报这类「多条信息并列」的内容，本质是一张报纸版面——灰阶承载全部信息量，一个强调色只标头条主角。读本文件请只带走**判断准则**——橙色、双线、字距都是某一期的排版，换一种信息结构必须重新布局。

## 判断准则（可迁移的决策逻辑）

1. **灰阶承载，强调只标主角**：全部信息用墨/灰层级表达，荧光橙只落一个「头条里的词」。判断：全卡数一遍橙色，超过一处就删到一处——多一处，重一分变轻一分。
2. **版面感来自结构，不来自装饰**：报头双线、栏目标签、来源行不是装饰，是报纸的「版面骨架」——它们把信息分成可扫读的区块。判断：删掉所有装饰性边框，版面结构还在吗？
3. **层级靠微差，不靠色块**：卡片底色只比纸底深一点点，区块像「版面分区」而非「视觉装饰块」。判断：区块之间的区别是「位置和留白」还是「色块」？后者是错。
4. **节奏由信息流决定**：大瓜双列、小料一列、脚注收尾——版式跟随内容重要度收缩，不是固定模板。判断：这条信息配得上现在的版面面积吗？

## 示例素材（落地样例 · 可替换）

- 色板：底 `#F0F0EE` / 墨 `#1F1E1C` / 灰阶 `#DBDAD3→#22211F` / 强调荧光橙 `#F5572F`（唯一）。
- 骨架：报头 `border-bottom:3px double` + 刊名加字距 → 头条大标题（强调色落标题两三个字）→ 双列 grid 新闻流 → 紧凑 list 小料 → 来源行（上边框 + 9.5px 全大写 + letter-spacing .08em）。
- 卡片底色 `#F9F8F5`（只比纸底深 1 档）；分类标签 `border-left:4px solid` + 800 字重。
- 字级阶梯（先生定调 · 六大类）：刊名最大（21px/800 加字距）→ 头条标题 20px/800 → 栏目标签 10px 加字距 → 正文 12.5px → 脚注 10.5px 居中 → 来源行 9.5px 全大写（全卡最弱）。

## 点睛技法

1. **报头双线立报格**——`border-bottom:3px double` 比单线有「报纸」的分量，刊名加 letter-spacing .35em 拉出印刷仪式感（今日八卦晚报实证）。
2. **强调色只给标题里的两三个字**——「今日瓜田**速递**」只染「速递」二字，最小面积最大冲击（判断准则 1 的实证）。
3. **分类标签用 4px 左边框 + 800 字重**，比 badge 更有「版面栏目」感；虚线胶囊 badge 留给条目类型，hot 变体才用强调色。
4. **来源多源并列用「· 」分隔**，链接 hover 才亮强调色——平时全部沉灰，不抢正文。
5. **尾部脚注收束全报**（居中 + 加字距）——像报纸的「编者按」。
6. **style 多行逐条、禁超长单行**——本风格规则多，更要把每条规则独立一行写（`#vcp-root .xx{短属性}`），行间无空行；压成单行会在流式渲染时溢出/闪动（先生实测 2026-08-28：蓝汐晚报卡先溢出后闪动，改多行即稳；动画无罪，参考卡满屏动画依然稳定）。
