# 美学风格索引（styles/_INDEX.md）

> 用法：输出视觉内容前，先 read 本文件（约 200 token）→ 按场景/标签命中风格 slug → read `styles/<slug>.md` → 按该文档的色板与技法组织视觉。每个风格文档都继承常驻【审美底线·公约】，只写差异化准则。
> 未命中 / 无工具 / 检索失败 → 读 `styles/_BASELINE.md`（兜底基准库：四色系/卡片骨架/图型/动效）保底，不再纠结。
> 新增风格：在此追加一行，并新建 `styles/<slug>.md`（模板见 wabi-sabi.md 骨架）。
