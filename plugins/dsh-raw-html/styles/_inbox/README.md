# 网络素材暂存区（styles/_inbox/）

> 这是「吸纳网络优良素材」管道的**入口暂存区**——只放未拆解的原始素材，不放正式风格文档。
> 流程四步（详见 审计-2026-08-26 §七·7.3）：**采集 → 拆解 → 入库 → 验证**。
> 本目录内容不属于已索引风格，agent 检索时**不读本目录**；正式风格文档一律放 `styles/` 并登记 `_INDEX.md`。

## 怎么用（给所有 agent 的协作约定）

1. **采集**：看到好设计（网页/海报/杂志/App/Behance/Dribbble），在此存一条素材卡——
   格式见下 `素材卡模板`。一次性多存，攒够再提炼，不边看边入库。
2. **拆解**（核心步骤，入库前必做）：对每条素材回答三问——
   - 可迁移的**判断准则**是什么？（决策逻辑 → 写入正式风格文档）
   - 不可迁移的**具体参数**是什么？（色值/字号/留白 → 标「示例」）
   - 属于已有风格 / 需要新建哪个风格？
3. **入库**：按 `styles/wabi-sabi.md` 骨架（元信息/判断准则/示例素材/点睛技法）写成正式文档，
   `_INDEX.md` 加一行，本素材移出 `_inbox/`。
4. **验证**：下一张同类卡片用它 → 被先生点赞 → 回填「点睛技法」；没被点赞 → 不扩散。

## 入库门槛（强制）

只有满足其一才允许从本目录提炼入库：
- 「先生点赞」的成品提炼的技法；
- 同一技法被复现 ≥3 次；
- 网络素材经拆解后「判断准则」与「参数」分离提取。

一次性灵感、未经拆解的截图**不得**直接入 `styles/`，先进本目录。

## 素材卡模板

```
来源：<URL 或出处>（截图存同目录）
好在哪：<一句话，如「节奏靠极窄发丝线 + 大留白」>
判断准则（可迁移）：<决策逻辑，入库时写进正式文档>
示例参数（不可迁移）：<色值/字号/留白量，标注「示例」>
归属：<已有风格 slug / 建议新建风格名>
```
