# 侘寂 · 文学散文风（wabi-sabi）

> 继承公约：本风格继承常驻【审美底线·公约】（对齐成网/一屏一焦点/明度即层级/吝啬即重量/留白分卡/色彩 60-30-10/字体三员/图必有义/禁 Emoji/数据诚实/字级阶梯），以下只写差异化准则。

> 元信息：
> - 主义/流派：侘寂 / 残缺美学 / 物哀
> - 适用场景：文学、散文、书信、禅意、梦境叙事、人物小传
> - 标签：文学, 散文, 禅, 留白, 纸感, 枯寂, 书信
> - 色板（示例基调，随语境调）：底 `#F5F2EC` / 墨 `#3D3831` / 点缀 枯茶 `#A0845C` / 灰阶 纸→墨
> - 字体：正文楷书（Lanxi-WenKai）或宋体；标题可用行草/瘦金书（需外置字体库）——文人气息也可选 `Lanxi-春兰茅坤`（Aa 今日花青，2026-08-28 入库）做雅集标题，诗意手写可用 `Lanxi-自由浪漫`

## 这是什么（不是模板，是思路）

本风格的核心命题：**留白是主角，内容在角落呼吸**。当内容是向内收的情绪（禅意、思念、枯寂），版式就要为「沉默」让出面积——不对称、低饱和、材质叙事，让读者在空白里读完没写出来的部分。读本文件请只带走**判断准则**——米纸、枯茶、楷书都是某一席茶会的布置，换一种心境必须重新落座。

## 判断准则（可迁移的决策逻辑）

1. **留白先于内容**：四周 padding 比数据卡大一圈、行距 1.8 起步、段落之间奢侈留白——让呼吸感成为版式本身。判断：把留白填满，这首诗还剩什么？
2. **不对称是有意的**：不用对称 grid，单列 + 错落——诗块偏右下、题签偏左上，「失衡」本身就是侘寂的表情。判断：这个偏移是设计还是失误？失误就归位，设计就坚持。
3. **点缀色吝啬到底**：枯茶全卡最多 2 处（标题一横、落款一枚）。判断：数一遍，超过两处就删——删到只剩「呼应」。
4. **材质替装饰说话**：纸纹、极淡墨晕（径向渐变模拟）、发丝分隔线——拒绝玻璃拟态、拒绝发光。判断：每层渐变答得出「光从哪来/纸是什么纸」吗？
5. **中文排版铁律从严**：首行缩进 2em、全角标点、弯引号「」『』、两端对齐——侘寂的「素」从规范里长出来，不是自由发挥出来的。

## 示例素材（落地样例 · 可替换）

- 色板：底 `#F5F2EC` / 墨 `#3D3831` / 点缀枯茶 `#A0845C`（≤2 处）。
- 版式：内容缩一角（如右下）+ 题签/落款在对角呼应；行距 2.3-2.7、字距 0.04-0.06em；楷书正文。
- 材质：纸感底（近白偏暖）+ 极淡径向渐变模拟墨晕；发丝线做分隔。
- 字级阶梯（先生定调 · 六大类）：标题楷书 17px 枯茶或墨 → 诗体楷书 15.5px 行距 2.7（正文级）→ 题签/干支 10px 加字距（装饰级，弱于诗体）→ 落款最小。留白本身也是层级的一部分。

## 点睛技法

1. **文学叙事是甜蜜陷阱（跨风格警示 · 2026-08-25 雨柬系列实证 · 其他 agent 共建）**——纸很美，热很真：文学风卡片必须先问「内容是什么强度」，再定修辞方向；数据/事实是空气，修辞是香水，香水不能代替空气。完整解法见 `ink-letter`。
2. **空出来的部分才是诗**——四句五言配七成留白：读者不是读字，是读「字与空的间距」。判断：删掉一半行距，诗还在，韵没了。
