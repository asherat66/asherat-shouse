# 暖调极简轻奢 · 空灵轻盈风（warm-minimal）

> 继承公约：本风格继承常驻【审美底线·公约】（对齐成网/一屏一焦点/明度即层级/吝啬即重量/留白分卡/色彩 60-30-10/字体三员/图必有义/禁 Emoji/数据诚实/字级阶梯），以下只写差异化准则。
> 元信息：
> - 主义/流派：暖调极简主义 / 空灵轻盈 / 低视觉重量高质感
> - 适用场景：高端音频/软件产品展示页、个人名片、品牌介绍、优雅落地页、技术文档——「内容为王，视觉退隐」
> - 标签：极简, 轻奢, 暖调, 留白, 空灵, 高端, 纸感
> - 色板（示例基调，随语境调）：暖白底 `#f5f5f5` / 纯白卡 `#ffffff` / 暖石 `#f5f2ef` / 文字黑 `#000`·深灰 `#4e4e4e`·暖灰 `#777169`——**绝对禁用冷灰 `#cccccc`**
> - 字体：标题 `Lanxi-朗宋` / `Lanxi-颜宋`（30px 档，柔而有骨）；副标题 `Lanxi-品宋`；正文 `Lanxi-可宋` 15px（先生实证：宋体横细竖骨，清晰雅致）；装饰 `Lanxi-静黑超细`（仅水印/英文点缀，禁止承载任何信息）；**禁用粗体 700**；**可读红线——正文一律 ≥14px 字重 400 起，`Lanxi-静黑超细` 只许装饰层**
> - 可混配：× editorial-minimal（商务的「轻盈+深度」双档）、× porcelain-data（数据卡的低噪感）

## 这是什么（不是模板，是思路）

本风格的核心命题：**用极轻的视觉重量，传达极高端的品质感**。像一间高级音响陈列室——纯白墙面、暖灰地毯、极暗灯光，只有极细的文字和巨大的留白在呼吸。读本文件请只带走**判断准则**——Inter/暖石色是一组示例，换成细衬线+淡青点缀就是另一种轻盈。

## 判断准则（可迁移的决策逻辑）

1. **轻字重即品牌，可读性兜底**：标题用超细字重（300），打破「大标题要粗」的惯性——纤细是它的高级感来源，但纤细只属于装饰层：**字重 300 及以下一律不得用于正文与信息承载**（正文 400/500 起、≥14px），超细只许出现在 24px 以上大标题/水印/点缀。判断：任何需要「读」的内容出现字重 <400 或字号 <14px，先保可读再谈风格。
2. **暖克制，禁冷灰**：极简不是黑白灰，是「暖调无彩色」——暖白底 + 暖棕阴影（`rgba(78,50,23,…)`），让阴影与背景产生反射关系。判断：出现 `#cccccc` 或冷灰，风格立刻掉一档。
3. **微阴影哲学**：多层堆叠阴影（内嵌半像素 + 1px 描边 + 外阴影），不透明度全压制在 0.1 以下——「表面几乎不存在，只是悬浮在纸面上」。判断：阴影明显到看得见边界，就过头了。
4. **字距内紧外松**：标题字距为负（收紧重心），正文字距为正（+0.01~0.02em 拉开透气）。判断：标题和正文用同一种字距，节奏就平了。
5. **重音只给一处**：唯一的「重音」留给 CTA——粗体 700 全大写，像寂静中的一声惊雷。判断：全卡数一遍粗体，超过一处就删。
6. **留白像博物馆展品**：区块间距极大，每部分独立存在；内容 max-width 克制，阅读像在逛展。

## 示例素材（落地样例 · 可替换）

- 色板：暖白底 `#f5f5f5` / 纯白卡 `#ffffff` / 暖石按钮 `#f5f2ef`（80% 透明）/ 字 黑·深灰·暖灰三级；阴影 `rgba(78,50,23,0.04)`。
- 骨架：顶部 11px 全大写加字距小标签 → 中文大名 32px 朗宋/颜宋 → 英文副题 16px 品宋 → 极细分割线 → 可宋正文 15px；卡片 16-24px 圆角 + 极浅边框。
- 质感：白卡像「落在暖灰桌面的羽毛」——1px 极淡描边 + 0.04 阴影；按钮药丸形 9999px 圆角、非对称内边距（右留白更多，向右引导）。
- 交互：按钮悬停瞬间暖石半透明 → 纯黑底 + 纯白字，优雅且极具冲击。
- 装饰：背景英文大词 1.5% 透明度，像拓印在宣纸上的水印，只求意境不干扰阅读。

## 点睛技法

1. **中英双语必须共存**——东方人名的西方表达：中文大名 + 英文拼音副题，是名片级仪式感。
2. **「越细越贵」的心理暗示**——纤细标题 + 巨大留白 + 低透明度阴影，三件套缺一即塌。
3. **唯一重音=响指时刻**——CTA 是全卡唯一粗体 700 全大写，与四周轻盈形成极致反差。
4. **宋体分工即层次**——可宋正文（稳）、品宋副题（雅）、朗宋/颜宋标题（骨）、静黑超细水印（空）：同是宋系、各司其职，一套字体撑起整张卡的呼吸感。
