# 粗野主义 · 反精致积木风（brutalism）

> 继承公约：本风格继承常驻【审美底线·公约】（对齐成网/一屏一焦点/明度即层级/吝啬即重量/留白分卡/色彩 60-30-10/字体三员/图必有义/禁 Emoji/数据诚实/字级阶梯），以下只写差异化准则。
> 元信息：
> - 主义/流派：粗野主义 / 新粗野主义 / 反精致积木
> - 适用场景：先锋品牌、独立产品、态度宣言、硬核社区、实验内容、游戏/音乐亚文化——凡是「要有鲜明态度」的地方
> - 标签：粗野, 硬核, 色块, 直角, 硬阴影, 态度, 先锋
> - 色板（示例基调，随语境调）：纯黄 `#FFEB3B` / 纯红 `#FF5252` / 纯蓝 `#2196F3` / 荧光绿 / 深紫 / 纯黑——**拒绝过渡色，只用纯色高对比**
> - 字体：极粗无衬线（英文 Archivo Black / 中文 `Lanxi-超粗黑`·`Lanxi-狂侠体`），超大号溢出容器

## 这是什么（不是模板，是思路）

本风格的核心命题：**用「绝对确定性和鲜明态度」砸向观众**。它抛弃讨好眼球的细腻过渡，用极度平面的色块和生硬的几何线条，把信息直接怼在脸上。它不追求美，追求「绝对确定性和鲜明态度」。读本文件请只带走**判断准则**——纯黄纯红纯蓝是一组示例，换成荧光绿×纯黑就是另一种攻击性。

## 判断准则（可迁移的决策逻辑）

1. **反精致是立场**：对抗玻璃拟态/柔和平滑阴影/过度圆润——0 圆角（不让步），拒绝细腻过渡。判断：出现柔和渐变或大圆角，态度就软了。
2. **错位与挤压**：元素故意压住边缘、超出容器、相互重叠，制造「破坏完美」的冲突。判断：排得整整齐齐，就不是粗野主义。
3. **超大×超小两极**：标题大到溢出容器，正文小到对比悬殊——大小反差制造视错觉。判断：标题和正文差不多大，冲击力就没了。
4. **硬阴影是积木的厚度**：`4px 4px 0 #000` 的实心阴影，不是装饰，是「积木块」的立体感。判断：阴影变成柔和的模糊投影，就从积木变成了纸片。
5. **高饱和色块拼贴**：几个巨大的、反差强烈的纯色块像拼贴画一样控制视觉重心，制造噪音与张力。判断：颜色超过 4 个还都用得平均，就乱成噪音（公约 60-30-10 仍适用，只是都是纯色）。
6. **间距走极端**：要么紧贴（元素挨在一起），要么极其空旷（大面积纯色留白）——不设中间态。

## 示例素材（落地样例 · 可替换）

- 色板：纯黄 `#FFEB3B` / 纯红 `#FF5252` / 纯蓝 `#2196F3` / 纯黑 `#000` / 荧光绿——每屏 2-4 个大色块拼贴。
- 骨架：超大标题溢出容器（`font-size` 大到裁剪/越界）→ 纯色块堆叠（允许互相覆盖）→ 黑色粗边框勾勒边界 → 硬阴影按钮。
- 质感：0 圆角直角切割；`box-shadow:4px 4px 0 #000`；按钮按下 `translate(2px,2px)` 阴影消失（物理位移反馈）。
- 字级阶梯：主标题极端大（粗黑）→ 正文极端小（对比悬殊）→ 可混报纸铅字式多色多底纹段落。

## 点睛技法

1. **硬阴影方向感**——`4px 4px 0` 统一右下，让所有元素像同一光源下的积木。
2. **出界是设计不是失误**——标题或色块故意伸出容器 2-3 个字符，打破完美边界。
3. **现代粗野主义进化**——加欧普条纹背景、低像素噪点、扫描线动画，从「复古粗野」走向「赛博粗野」。
